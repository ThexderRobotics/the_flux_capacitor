Handy tools for everyday tech.

Use these privacy-friendly utilities for passwords, networks, data formats, and troubleshooting. They run locally in your browser except for website ping requests.

Password generator

Create a random password using your selected character types.

How secure is my password?

See a rough estimate of how long an offline guessing attack might take.

Enter a sample password to estimate its crack time.

This is a rough random-guessing estimate at 10 billion guesses per second, not a guarantee. Common, reused, or breached passwords can be cracked much faster. The check runs locally; do not enter a password you currently use.

Website ping

Measure how quickly your browser reaches a website over HTTPS. This is an HTTP timing check, not an ICMP ping.

Runs four HTTPS checks. ICMP ping is not available in web browsers.

    Four small HTTPS requests are sent directly from your browser to the entered site. Results can vary with network conditions and the site's response.
